# DeskMode — واجهة سطح مكتب لأندرويد (بأسلوب DeX)

تطبيق Launcher مفتوح المصدر بتصميم أصلي مستوحى من وضع سطح المكتب:
سطح مكتب بالأيقونات، شريط مهام، قائمة ابدأ مع بحث، ساعة وبطارية، وفتح التطبيقات في نوافذ عائمة.

## البناء
1. افتح المجلد في **Android Studio** (Koala أو أحدث) ← سيُنشئ Gradle wrapper تلقائياً.
2. وصّل هاتفك (تصحيح USB) واضغط Run، أو Build ← Build APK.

## التشغيل
- افتح التطبيق من قائمة التطبيقات، أو اضغط زر Home واختر DeskMode ← "دائماً".
- على شاشة خارجية (HDMI / لاسلكي) يظهر سطح المكتب تلقائياً عبر SECONDARY_HOME.

## تفعيل النوافذ العائمة (مهم)
خيارات المطوّر ← فعّل:
- Enable freeform windows
- Force activities to be resizable
ثم أعد تشغيل الهاتف. بدونها ستفتح التطبيقات بملء الشاشة بدل نوافذ.

## الاستخدام
- نقرة: فتح في نافذة · ضغطة مطولة: فتح بملء الشاشة / تثبيت في شريط المهام / معلومات.
- ضغطة مطولة على أيقونة الإعدادات: تذكير بتفعيل النوافذ.

## قيود
- لا يمكن لتطبيق عادي تحريك/تكبير/إغلاق النوافذ بالسحب بنفس طريقة DeX الأصلي (هذا من النظام نفسه).
- شريط المهام يعرض فقط التطبيقات المُطلقة من DeskMode.
